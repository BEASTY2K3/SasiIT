# IT Skills for Employment &mdash; Master Presentation Suite

**Course Title:** IT Skills for Employment (Common to all UG programmes)  
**Category / Semester:** Semester III | Non-Major Elective (NME)  
**Credits & Hours:** Theory | Credits: 2 | Hours/Week: 2  
**Institution:** Sasi College  

---

## Course Objectives
1. **Computer Hardware &amp; Architecture:** Understand internal physical components, buses, storage hierarchies, peripheral devices, and operating system mechanics.
2. **Office Productivity &amp; Digital Fluency:** Master the corporate triad &mdash; ATS-compliant Word documents, dynamic Excel modeling, and executive PowerPoint delivery.
3. **Cloud Systems, Digital Governance &amp; Cybersecurity:** Navigate cloud collaboration, citizen e-portals, UPI payments, cyber threat defense, and statutory provisions under the IT Act, 2000.

---

## Comprehensive 275-Slide Curriculum Architecture

Every topic in the university syllabus is expanded into a **strict 3-slide pedagogical sequence**:
* **Part 1 &bull; Conceptual Foundations &amp; Visual Showcase:** Deep-dive physical principles, microarchitecture, and high-resolution technical figure card with student discussion points.
* **Part 2 &bull; Comparative Analysis &amp; Technical Cheatsheet:** Exhaustive tabular matrices, specifications, operational trade-offs, and parameter comparisons.
* **Part 3 &bull; Enterprise Application &amp; 2026 Workplace Trends:** Real-world workplace scenarios, step-by-step diagnostic workflows, efficiency shortcuts, and modern industry best practices.

### Deploying to Vercel

#### Method 1: Git Integration (Recommended)
1. Push this repository to GitHub, GitLab, or Bitbucket:
   ```bash
   git add .
   git commit -m "Restructure project for Vercel deployment"
   git push origin main
   ```
2. Import the repository in [Vercel Dashboard](https://vercel.com/new).
3. Vercel automatically detects `vercel.json` and deploys the `public/` directory with clean URLs enabled. No manual configuration needed!

#### Method 2: Vercel CLI
```bash
npx vercel
```
When prompted, confirm default settings. Vercel will deploy using `vercel.json`.

### Local Development

Preview the static site locally:
```bash
# Using Node / npx
npm run dev

# Or using Python 3
python3 -m http.server 3000 --directory public
```
Visit `http://localhost:3000` in your web browser.
