UNIT 1: COMPUTER HARDWARE & FUNDAMENTALS • SOLUTIONS (Q01 – Q05)
Question 01 CORRECT ANSWER: (C) Central Processing Unit (CPU)
Topic 04: Processor (CPU) Role & Central Architecture
"Which internal component is widely known as the 'Brain' of the computer because it interprets and executes program instructions and performs all calculations?"
Why (C) is Correct: The Central Processing Unit (CPU) is known as the brain of the computer. It fetches instructions from memory, decodes them, and executes them (performing arithmetic, logical, and control operations).
Option (A) is Incorrect: A Monitor is an output display device that shows visual output, not an instruction processor.
Option (B) is Incorrect: A Hard Disk Drive is secondary storage used to hold files permanently, not to calculate or execute code.
Option (D) is Incorrect: A Keyboard is an input hardware peripheral used for typing characters.
Question 02 CORRECT ANSWER: (B) Random Access Memory (RAM)
Topic 05: Primary Memory (RAM vs. ROM Volatility)
"Which type of computer memory is 'volatile', meaning that all data stored in it is instantly erased when the computer is turned off or restarted?"
Why (B) is Correct: RAM (Random Access Memory) is temporary, volatile working memory. When you open applications, they are loaded into RAM for fast access by the CPU. When electrical power is switched off, everything in RAM is wiped clean.
Option (A) is Incorrect: ROM retains essential startup instructions permanently even without electrical power.
Option (C) is Incorrect: Hard Disk Drives provide persistent secondary storage that keeps your files safe when the power is off.
Option (D) is Incorrect: USB Pen Drives use non-volatile flash memory to store portable files permanently.
Question 03 CORRECT ANSWER: (A) Computer Keyboard
Topic 13 & 15: Input vs. Output Peripherals
"Which of the following devices is strictly an **Input Device** used to enter data, text, and commands into the computer?"
Why (A) is Correct: A keyboard is an input device that allows users to send alphanumeric keystrokes and control signals directly into the computer.
Option (B) is Incorrect: A Display Monitor is an output device that visually presents data to the user.
Option (C) is Incorrect: A Laser Printer is an output device that creates physical paper copies of digital documents.
Option (D) is Incorrect: An Audio Speaker is an output device that converts digital audio signals into audible sound waves.
Question 04 CORRECT ANSWER: (D) Solid State Drive (SSD)
Topic 09 & 10: Secondary Storage Media (HDD vs. SSD)
"What type of modern storage drive uses electronic flash memory chips with zero spinning parts, providing significantly faster boot and file opening speeds than a mechanical Hard Disk?"
Why (D) is Correct: Solid State Drives (SSDs) use electronic NAND flash memory chips. Because they have no moving mechanical parts, they access files almost instantaneously compared to spinning hard disk platters.
Option (A) is Incorrect: CD-ROM is an optical disc format read by an optical laser drive.
Option (B) is Incorrect: Floppy Disks are obsolete magnetic storage media that held only 1.44 MB.
Option (C) is Incorrect: Magnetic Tape is a sequential tape format primarily used for legacy offline archiving.
Question 05 CORRECT ANSWER: (B) Local Area Network (LAN)
Topic 18: Computer Network Scope (LAN vs. WAN)
"A computer network that interconnects computers and devices within a limited physical geographical area, such as a single computer lab, office building, or college campus, is known as a:"
Why (B) is Correct: LAN (Local Area Network) connects computers and printers within a small, confined area like a home, lab, or office building, allowing fast local data transfer and hardware sharing.
Option (A) is Incorrect: A WAN (Wide Area Network) spans broad geographic boundaries like states, entire countries, or the globe (e.g. the Internet).
Option (C) is Incorrect: A MAN (Metropolitan Area Network) covers an entire city or large municipal region.
Option (D) is Incorrect: Satellite networks connect stations across orbit for intercontinental telecommunications.

"What is the primary function of an **Operating System** (such as Windows 10, macOS, or Linux) on a personal computer?"

Question 07 CORRECT ANSWER: (C) Ctrl + C
Topic 32: Universal Windows Keyboard Shortcuts
"Which standard keyboard shortcut is used in Windows and Microsoft Office to **Copy** selected text, images, or files to the clipboard?"
Why (C) is Correct: Ctrl + C copies the selected item onto the system clipboard while leaving the original item in place.
Option (A) is Incorrect: Ctrl + X cuts the selected item (removes it from its current position to the clipboard).
Option (B) is Incorrect: Ctrl + V pastes the copied or cut item from the clipboard to the cursor position.
Option (D) is Incorrect: Ctrl + Z undoes the most recent user action.
Question 08 CORRECT ANSWER: (D) Recycle Bin
Topic 26: Windows File Explorer & File Recovery
"When you delete a document or folder from your hard drive by pressing the `Delete` key in Windows, where does it temporarily go so you can easily restore it if needed?"
Why (D) is Correct: The Windows Recycle Bin serves as a safety holding area for deleted files on local drives, allowing users to restore mistakenly deleted items back to their original folder.
Option (A) is Incorrect: Device Manager manages hardware drivers and peripheral connections.
Option (B) is Incorrect: Control Panel configures operating system and hardware settings.
Option (C) is Incorrect: Windows Update installs security patches and operating system feature updates.
Question 09 CORRECT ANSWER: (A) Disk Cleanup (or Storage Sense)
Topic 29: System Maintenance & Disk Hygiene
"Which built-in Windows maintenance tool safely scans your hard drive to find and delete temporary files, system cache, and empty the Recycle Bin to free up disk storage?"
Why (A) is Correct: Disk Cleanup (and Windows 10 Storage Sense) scans storage drives for temporary Internet files, setup logs, thumbnail caches, and recycle bin items, safely reclaiming valuable gigabytes of space.
Option (B) is Incorrect: Paint 3D is a simple raster and 3D modeling creative tool.
Option (C) is Incorrect: Windows Media Player is an application used for playing music tracks and video files.
Option (D) is Incorrect: Notepad is a lightweight plain text editor.
Question 10 CORRECT ANSWER: (B) Windows Key + L
Topic 25: Workplace Security & Screen Hygiene
"When stepping away from your workstation or computer desk in an office or college lab, which keyboard shortcut instantly **Locks** your Windows screen to prevent unauthorized access?"
Why (B) is Correct: Pressing Windows Key + L immediately locks your Windows session. Your open apps and documents remain intact in the background, but the computer cannot be accessed without entering your password/PIN.
Option (A) is Incorrect: Alt + F4 closes the currently active program window.
Option (C) is Incorrect: Ctrl + Shift + Esc directly opens the Windows Task Manager.
Option (D) is Incorrect: Windows Key + P opens the multi-monitor display projection menu.

Question 12 CORRECT ANSWER: (D) Equal sign (`=`)
Topic 43: MS Excel Formula Syntax Fundamentals
"In Microsoft Excel, what symbol MUST you type as the very first character in a cell to tell Excel that you are entering a mathematical formula or calculation?"
Why (D) is Correct: In Microsoft Excel, every formula or function must begin with an equal sign (`=`). Without it, Excel treats the entered text as a plain label or string rather than a calculation.
Option (A) is Incorrect: A plus sign is an addition operator inside formulas, not the standard initiating formula trigger.
Option (B) is Incorrect: Hashtags are used in error indicators (like `###` when a column is too narrow).
Option (C) is Incorrect: Dollar signs are used inside formulas to create absolute cell references (e.g. `$A$1`).
Question 13 CORRECT ANSWER: (B) `=SUM(A1:A10)`
Topic 44: Core Spreadsheet Calculation Functions
"Which Excel function is used to calculate the combined total of numbers across a specified range of cells (for example, adding all numbers from cell A1 to A10)?"
Why (B) is Correct: The `=SUM()` function is the standard Excel function that adds all numeric values across the given cell range.
Option (A) is Incorrect: `=ADD()` is not a valid built-in Microsoft Excel formula.
Option (C) is Incorrect: `=TOTAL()` is not a recognized function in Excel.
Option (D) is Incorrect: `=COUNT()` counts how many cells contain numbers in a range, but does not calculate their total sum.

Question 18 CORRECT ANSWER: (C) BCC (Blind Carbon Copy)

"When sending an official email to multiple recipients, which address field should you use to hide recipient email addresses from each other to preserve their privacy?"

Option (A) is Incorrect: The 'To' field displays all recipient email addresses publicly to everyone who receives the email.

Question 20 CORRECT ANSWER: (D) You NEVER enter your UPI PIN to receive money; entering your UPI PIN is only required when you are transferring (paying) money OUT of your account.
Topic 70: Digital Payments & UPI Security Principles
"When using UPI mobile payment apps (such as Google Pay, PhonePe, or Paytm), which is the most critical security rule regarding your secret **UPI PIN**?"
Why (D) is Correct: The golden rule of UPI is that receiving money NEVER requires entering your PIN. Entering your UPI PIN is strictly and exclusively used to authorize deductions (debiting money) from your bank account.
Option (A) is Incorrect: Believing you must enter a PIN to receive money is the most common scam trick used by cyber fraudsters to steal money.
Option (B) is Incorrect: Legitimate customer support representatives will never ask for your private PIN or OTP.
Option (C) is Incorrect: Lottery/refund claims asking for a PIN are fraudulent phishing attempts.
UNIT 5: CYBER SECURITY, THREATS & ONLINE SAFETY • SOLUTIONS (Q21 – Q25)
Question 21 CORRECT ANSWER: (A) Malware (Malicious Software)
Topic 71 & 72: Malware Threat Definition
"What broad term is used to describe any harmful computer software (such as viruses, worms, and spyware) intentionally designed to damage, spy on, or steal data from a computer?"
Why (A) is Correct: Malware is an umbrella term short for 'Malicious Software'. It encompasses computer viruses, worms, trojans, ransomware, spyware, and adware created to harm systems or steal information.
Option (B) is Incorrect: Hardware refers to the tangible, physical components of a computer (cables, chips, monitor).
Option (C) is Incorrect: Freeware is legitimate software distributed free of monetary charge for users.
Option (D) is Incorrect: Firmware is permanent low-level code programmed into read-only memory chips.
Question 22 CORRECT ANSWER: (C) To detect, prevent, quarantine, and remove malicious viruses and security threats from your computer
Topic 81: Antivirus Defense Mechanisms
"What is the primary function of installing an **Antivirus** software application (such as Windows Defender or Quick Heal) on your computer system?"
Why (C) is Correct: Antivirus software constantly scans system files, incoming downloads, and removable USB drives to detect malware signatures and suspicious behavior, isolating or deleting threats before they cause damage.
Option (A) is Incorrect: Antivirus does not alter physical internet bandwidth provided by your telecom service provider.
Option (B) is Incorrect: Antivirus is software; it cannot physically repair broken electrical cables or cracked monitors.
Option (D) is Incorrect: Antivirus does not increase the physical capacity of storage hardware.
Question 23 CORRECT ANSWER: (B) Phishing
Topic 83: Social Engineering & Phishing Attacks
"What type of online cyber scam involves fraudulent emails or fake website messages that pretend to be from trusted banks or organizations to trick you into giving away your passwords or card numbers?"
Why (B) is Correct: Phishing is a form of social engineering where attackers impersonate trustworthy entities (like banks, payment apps, or college portals) through deceptive emails or links to steal credentials, passwords, or credit card details.
Option (A) is Incorrect: Defragmentation is a system maintenance routine that arranges file clusters on a hard drive.
Option (C) is Incorrect: Screen Casting is a feature used to wirelessly stream your computer screen to a TV or projector.
Option (D) is Incorrect: Data Compression reduces file size (e.g. creating a ZIP archive).
Question 24 CORRECT ANSWER: (D) A combination of at least 8 to 12 characters including uppercase and lowercase letters, numbers, and special symbols (e.g., `@`, `#`, `!`)
Topic 87: Password Hygiene & Account Protection
"Which of the following practices creates the strongest, most secure **Password** to protect your personal and email accounts from hackers?"
Why (D) is Correct: A strong password combines length (at least 8–12 characters) with complexity (uppercase letters, lowercase letters, digits, and special symbols). This makes it computationally infeasible for hackers to guess via brute-force or dictionary attacks.
Option (A) is Incorrect: Names combined with `123` are among the top 10 most easily cracked passwords globally.
Option (B) is Incorrect: Birthdays and phone numbers are easily discovered through social media profiling.
Option (C) is Incorrect: 'password' is the single most commonly cracked password in cyber security history.
Question 25 CORRECT ANSWER: (C) 1930
Topic 90: National Incident Reporting & Help Desk
"Which official National Cyber Crime toll-free helpline number has been launched by the Government of India for citizens to immediately report financial cyber frauds and digital online crimes?"
